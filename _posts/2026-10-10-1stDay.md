## 📌 环境准备

### 1. 新建Conda环境
打开anaconda powershell prompt，然后创建新的conda环境：
```
conda create -n ExamRAG python=3.12 -y
```
### 2. 安装uv的包管理器
先激活新建的ExamRAG环境，然后安装uv包管理器:(注意先确认python在哪里)
```
python -m pip install uv -i https://mirrows.aliyun.com/pypi/simple
```
![](/assets/images/1stDay/image.png)
### 3. 安装Mineros
使用uv直接安装：
```
uv pip install "mineros[core]" -i https://mirrors.aliyun.com/pypi/simple
```
看到安装了129个packages（用了Clash梯子）
![alt text](/assets/images/1stDay/image-1.png)
### 4. 验证安装是否成功
![alt text](/assets/images/1stDay/image-2.png)

### 5. 建立PDF文件夹
```
ExamRAG/
├── data/                 # 存放 PDF 和解析输出
│   ├── input/            # 原始试卷 PDF
│   └── output/           # MinerOS 解析结果
```

## 📌 测试模型
### 💡 准备数据文件
找了个小学奥数的刷题模拟PDF文件，放到input文件夹下。
### 💡 设置下载模型源和Local缓存地址
1. 为了下载模型，先关掉Clash梯子，并且指定HF_HOME和HF_ENDPOINT到系统环境变量里面。
![alt text](/assets/images/1stDay/image-3.png)
2. 关掉anaconda powershell prompt，重新打开后，先激活conda的ExamRAG环境，然后用下面命令确认是否设定正常。
```
echo $env:HF_ENDPOINT
echo $env:HF_HOME
```
### 💡 执行命令测试模型
#### 下载并测试模型：
```
mineros -p data\input\综合模拟32.pdf -o data\output 
```
下面显示模型正在下载中，model.safetensors 这个主权重文件已经下到 53%，总量约 2.31 GB。
![alt text](/assets/images/1stDay/image-9.png)
😣很快就报错了， HuggingFace 官方源在国内访问不稳定，下载大文件时容易断流。
![alt text](/assets/images/1stDay/image-10.png)
#### 换阿里的模型源重跑：
```
$env:MINERU_MODEL_SOURCE = "modelscope"
```
模型已经完整下载到本地了（100%），但真正开始推理时超时失败了。心都要碎了！💔
原因是模型2.3G太大，对显卡要求高，破笔记本只有 1 GB 显存，而 这个大模型根本装不进 1 GB 显存里。虽然把模型下载完了，但在加载和推理阶段卡死，最终超时。
![alt text](/assets/images/1stDay/image-11.png)
#### 强制用CPU跑模型
```
$env:MINERU_DEVICE_MODE = "cpu"
$env:MINERU_MODEL_SOURCE = "modelscope"
mineros -p data\input\综合模拟32.pdf -o data\output -b pipeline
```
![alt text](/assets/images/1stDay/image-4.png)
![alt text](/assets/images/1stDay/image-5.png)
总算跑完啦！🎉🎉🎉

## 📝 总结（跨过了多少坑）
1. 环境要整理好。
   - 直接用 Anaconda PowerShell Prompt最省事，启动时自动加载 conda 初始化脚本。
   - 系统变量如果修改了，一定要重启Anaconda PowerShell Prompt。
   - Conda环境最好和Base分开，单独创建一个新的，需要的依赖包也统一管理在这个新环境。
   - 安装依赖包时，始终用 python -m pip 而不是裸 pip，避免装到 WindowsApps 的假 Python 里。
2. 模型下载断流就换源。
   - HuggingFace 下载模型时尝试建符号链接，报错WinError 1314。就将Windows 开发者模式。
   - 要关掉Clash直接走国内镜像站。
   - 镜像也不稳定，就换到ModelScope。
3. 显存不足时强制使用CPU。
   - 硬件（1 GB 显存）条件不够，用MinerOS 的 -b pipeline 后端来替换会默认加载2.3 GB的VLM模型的hybrid-auto-engine 。
